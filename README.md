# 云原神窗口推流（无 OBS · 不装直播姬采集源）

把**游戏窗口**的画面直接推进直播姬的「第三方开播」通道，全程 ffmpeg 一条命令，
不装 OBS、不用虚拟摄像头、不推整个桌面。双击就开播，点一下就停。

## 最简单的用法

1. 双击 `云原神开播.exe`。
2. 打开直播姬 → 模式选「第三方开播」→ 打开开播开关 → 复制它给的 `rtmp://` 地址。
3. 把地址粘到第一行（第一次打开时这一行是空的，只有一行灰字提示），打开游戏、进到游戏画面。
4. 点「开播」。

地址填一次就会记住，以后双击 → 点开播，两步。
**不用装 Python，不用装 ffmpeg，不用改配置文件** —— ffmpeg 已经打包在 exe 里了。

适用场景：云游戏客户端（云·原神之类）在 OBS / 直播姬里加「窗口捕获」永远黑屏，
或者只用核显、不想让 OBS 再开一套渲染管线的情况。

---

## 原理

1. `PrintWindow(hwnd, hdc, PW_RENDERFULLCONTENT)` 让目标窗口**自己重渲染一份**画面到内存位图。
   拿到的是这个窗口的内容，桌面上压着的浏览器、聊天窗、桌面图标都不会进来。
2. 位图通过 stdin 管道以 `rawvideo` 喂给 ffmpeg，用显卡硬件编码器（AMF / NVENC / QSV）压成 H.264。
3. 压好的码流推给直播姬的本地 RTMP（`rtmp://<本机IP>:1935/livehime`），由直播姬转给 B 站。
   走官方客户端开播，不受「第三方推流需 5000 粉」的限制。

实测：1080p 抓帧 60 fps（16.6 ms/帧），按 30 fps 推，CPU 占用约 2~4%，
内存约 120 MB，全程无窗口弹出（计划任务 + pythonw）。

## 依赖

**普通用户什么都不用装**：`云原神开播.exe` 是单文件绿色版，Python 和 ffmpeg 都在里面。

想从源码跑才需要：

- Windows 10 / 11
- Python 3.9+（只用标准库，不需要 pip 装任何东西；只有重新打包 exe 才需要 PyInstaller）
- ffmpeg（要带硬件编码器；`h264_amf` / `h264_nvenc` / `h264_qsv` 有一个就行，
  都没有会退回 `libx264` 软编，1080p30 会吃 CPU）
- B 站直播姬（用它的「第三方开播」模式）

ffmpeg 的找法：`config.json` 里的 `ffmpeg` → 系统 PATH 里的 `ffmpeg` → 几个常见目录。
建议显式填绝对路径，最省事。
